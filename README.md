# 📄 AI PDF Chatbot (Streamlit + OpenRouter)

This project is a **PDF-based AI Chatbot** built using Streamlit.  
It allows users to ask questions based on a document (PDF) and get intelligent answers.

---

## 🚀 Features

- 📄 Chat with PDF document
- 🤖 AI-powered responses
- 🧠 Conversation memory (remembers previous questions)
- 🌐 Web-based UI using Streamlit
- 🔗 Shareable via deployment

---

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenRouter API
- PyPDF2
